# v0.2.0 圣地、宗教影响力与信徒政治反应

状态：脚本实现与离线场景测试完成；1.13/1.14加载、AI、战争与存档尚未实测。

## 本轮实现

- 以耶路撒冷为首个圣地，关联天主教、新教、东正教、逊尼派、什叶派、犹太教。
- 每国分别维护各宗教的护教影响力和宗教权威（0—100），不是把伊斯兰教设为一个教宗体系。
- 天主教跨国领袖行动限教宗国PAP，初始权威60；其他宗教的国家级发声需同教国教、独立、威望≥50、神权制或限制性宗教政策、教权派势力≥20%。其他初始权威30。
- 领袖行动：呼吁克制（权威≥25）、护教号召（≥50、消耗10权威）、认可实际和解（≥25、增加5权威）。各国各宗教共享一年行动冷却；同一危机的和解只能被认可一次。
- 影响力和权威各自独立：有效响应危机的国家获得护教影响力+5及权威+5；公开承诺失败分别−10。附属身份每月降低权威1，不能发出独立领袖倡议。

## 地图与战争状态的诚实边界

当前没有城市省份级占领接口。圣地取 `s:STATE_PALESTINE` 中人口最多的state作为**区域代理**，跟踪其所有者，不声称精确定位耶路撒冷省份或每一次军事占领。分割地区时，人口大小变化也可能切换代理。该限制必须在扩展其他圣地前处理。

全局月度pulse只采样一次，国家月度pulse读取最后一个完整快照，因此允许最多一个月的延迟。

| 严重程度 | 触发条件 |
| --- | --- |
| 0 | 正常，首次建立基线不触发危机 |
| 1 | 区域代理所属国变化，持续一年；不自动推断迫害 |
| 2 | 统治者明确采取本Mod的礼拜限制，或地区破坏≥25%且所属国处于战争 |
| 3 | 地区破坏≥50%；是严重破坏代理，不是精确判断宗教建筑被毁 |

控制者可以恢复全部关联宗教的礼拜和朝圣；限制行动只对限制性宗教政策国家开放，AI不会自行采取限制。恢复通行不瞬间修复破坏，也不改变原版宗教接纳与宗教建筑。AI倾向开放通行，但真实执行需实测。

## 诉求与政府选择

相关宗教占本国人口≥1%，且有单个人口条目≥5,000时产生诉求，包括少数宗教。重要程度：基督教各派80、伊斯兰教各派85、犹太教100。只有同一宗教人口会收到该宗教的忠诚/激进效果。

| 政府回应 | 立即效果 | 后续 |
| --- | --- | --- |
| 不介入 | 无奖励 | 六个月后危机仍未解决，结算忽视代价 |
| 抗议与谈判 | 六个月−25影响力、−10行政力 | 权利实际恢复后才结算成果；未解决也不直接按背弃承诺惩罚 |
| 救济与通行协调 | 上述成本，另有六个月政府工资成本+2% | 同上，不因花钱就凭空增加忠诚 |
| 公开保护承诺 | 六个月外交行政成本，无即时忠诚奖励 | 若长期无成果则按背弃承诺结算；相关战争中期限可延长，最多24个月 |

这里的外交成本是容量修正，救济经费是政府工资比例成本代理，并没有把钱转入受援国财政。也没有宣称实现了自动外交谈判、跨国财政转移或国家间审批。

诉求出现至少三个月，且全局严重程度≤1、控制者已解除本Mod礼拜限制时，才可视为达成通行成果。此前选择抗议、救济或保护承诺的国家获得：相关宗教忠诚派+0.5%，护教影响力+5，权威+5，威望+5持续两年；若为本国国教，额外教权派认可+1两年。合作国可以共同受益，不要求某个国家独占成果。

危机持续六个月时：

- 公开承诺失败：相关宗教激进派+2%，护教影响力及权威各−10；若为本国国教，教权派认可−2一年。
- 无视低强度变化：相关宗教激进派+0.25%。
- 严重危机或宗教领袖号召下无视：一般+0.75%；圣地重要性≥85时+1%；若本国为该宗教国教且有强限制性宗教政策，+1.5%。
- 存在该宗教的克制呼吁时，忽视代价降至+0.25%，但不能抵消公开背约的+2%。

**每国每宗教五年内最多一次忠诚结算、一次激进结算。** 不按月累加，也不能靠反复控制权变化刷同一奖励。新危机替代旧诉求时不把旧诉求自动判为失约；新事件使用事件链独立的epoch快照，旧弹窗不能覆盖新回应。

原版政治运动会继续处理激进人口的政治后果；本轮没有脚本强行创建新革命、指定政治运动或让所有同教国家同时暴动。

## 圣地外交博弈

公开承诺且仍有有效诉求的国家，在严重程度≥2、拥有地区利益并满足原版外交条件时，可以从外交视图选择“恢复圣地礼拜与朝圣”。基础5恶名、20筹码，控制目标地区。

和平执行只撤销该地区本Mod礼拜限制，不转移领土、改国教或修复破坏。目标接受后，国家仍须等全局快照和政治结算条件满足才获奖励。已进入战争的目标不因诉求过期、权威或人口变化被删除。原版关系、停战、集团与宗主国限制依然适用；AI使用自定义博弈未验证。

## 数据与扩展

- `holy_sites.json`：首个圣地的region及关联宗教、重要性。
- `balance.json`：人口门槛、结算比例、期限、教权派门槛。
- `tools/holy_content.py`：生成宗教独立的状态机、事件、外交决议及本地化。
- `mod/common/scripted_effects/fia_holy_effects.txt`：生成的运行脚本。

当前生成器明确只接受单圣地试点。新增圣地需要先加入多圣地任务隔离，而不是复制共享全局变量。传教、定向改宗、国教人口统一增益、宗教保护国、任命护教国与宗教会议仍是后续功能。
